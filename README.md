# Immersive AI Portfolio

A bilingual AI product engineer portfolio built with React, Vite, TypeScript, and Tailwind CSS.

## Development

```bash
pnpm install
pnpm dev
```

## Verification

```bash
pnpm test
pnpm build
```

## Deployment

The site deploys to GitHub Pages through `.github/workflows/deploy.yml` whenever changes are pushed to `main`.
